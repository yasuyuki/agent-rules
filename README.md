# Agent Rules

Portable source rules and a deterministic renderer for Claude Code, Cursor,
and Codex workspaces.

This repository is a public alpha candidate. It is not yet the live source of
truth for the maintainer's environments.

## Requirements

- Python 3.10 or newer

## Usage

Render the managed rule files into a workspace:

```console
python3 bin/rules.py render <workspace>
```

Verify that a workspace still matches the source rules:

```console
python3 bin/rules.py verify <workspace>
```

`render` writes namespaced Claude rules under `.claude/rules/` and Cursor rules
under `.cursor/rules/`, preserving unrelated local overlays. Codex rules are
written as namespaced managed sections in `AGENTS.md`. `verify` returns a
nonzero status when generated content is missing, changed, duplicated, or
mixed with stale content in the managed namespace.

Unrelated rule files and root instructions are outside that namespace and are
left untouched. A malformed unmatched managed marker fails closed; repair that
marker before rendering so the tool never guesses how much local text to
remove.

## Source format

Each `rules/*.rule.md` file contains frontmatter with `id`, `title`, `summary`,
and `tools`. The body is shared policy text; optional tool-specific bindings
are selected by `placement.json`. Codex sections use the managed markers
generated by `bin/rules.py` and should not be edited by hand.

The catalog was derived from an evaluated private candidate, then reconciled
and sanitized for portable use. Private experiment history and environment
topology are not part of this repository.

## Development

```console
python3 tests/test_rules.py
```

The test renders and verifies a temporary workspace, confirms that drift is
rejected, then re-renders and verifies recovery.
