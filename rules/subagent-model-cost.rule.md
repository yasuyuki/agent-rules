---
id: subagent-model-cost
title: Subagent モデル選定
summary: ユーザー指定を優先し、未指定時は親以下の能力帯を既定にして必要な場合だけ上げる。
tools: [cursor]
---

subagent の model は原則として親 agent と同等以下にする。

1. ユーザーが model 名または variant を指定した場合は、それを優先し、勝手に別 family へ替えない
2. 指定がなければ model を省略して親の既定を継承する。高価な model を既定にしない
3. 親より高い能力帯は、複雑または曖昧で失敗コストが高く、同等以下では品質不足の可能性が高く、
   かつユーザーがコストまたは速度優先を指定していないときだけ使う
4. 上げる場合も必要な能力帯に限定し、検索、定型 shell、単純な編集、明らかな軽作業には使わない
5. 迷ったら上げない。指定された model は実行環境で利用可能な正確な指定として渡す
