title: セッション終了時のユーザー作業
summary: ユーザー自身の作業が残る場合だけ、最終応答末尾に即時実行可能な依頼を順序付きで示す。
tools: [cursor, claude, codex]
---

ユーザーが自分で行う作業が残るときだけ、最終応答の末尾に `## ユーザーへの依頼` を置く。
agent の次工程は `HANDOFF.md` に置く。この節が不要なら出力しない。

1. ユーザー作業を実行順の番号付きリストにする。command と画面操作は同じ番号列に混ぜ、先に行う操作を先に置く
2. command はそのままコピーして実行できる code block にし、既定と異なる shell または作業 directory だけを直前に示す
3. 画面操作は1 step につき1操作とし、開く場所、クリックまたは入力する内容、成功時に見える状態を示す
4. ユーザーの判断が必要な場合は該当 step の直前に明示し、操作手順と混ぜない
